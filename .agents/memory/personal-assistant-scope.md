name: Personal assistant scope
description: User-confirmed audience and ownership boundaries for Bertha.
---

Bertha is the user's personal assistant chatbot. The user selected “Only my conversations” for the interaction dashboard, not a dashboard of all visitors.

**Why:** The user explicitly described Bertha as “my personal assistant chatbot” and requested review of their own interactions.

**How to apply:** Scope history and appointments to the current owner. Do not expand the dashboard into cross-user monitoring or expose other visitors' conversations. If cross-device ownership becomes necessary, discuss account sign-in rather than treating a global collection as personal data.
